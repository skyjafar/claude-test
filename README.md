## Orbit Hop

A one-tap browser arcade game. You're a spark circling a sun on three orbit rings. Hop between rings to dodge red debris and grab gold stars.

**Play:** open `index.html` in any browser (or the GitHub Pages link, if enabled).

### Controls
| Action | Keyboard | Touch |
|---|---|---|
| Hop inward | ← ↓ A S | Tap left half |
| Hop outward | → ↑ D W | Tap right half |
| Pause | P / Esc | — |
| Mute | M | 🔊 icon (top right) |

### Scoring
- +1 per second survived
- +5 per star, multiplied by your combo (grab stars within 2.5s of each other, up to x5)
- Red dashed circles are warnings: debris appears there a moment later
- After ~18 seconds, debris "walls" block two rings at once, so find the gap

Your best score is saved in your browser.
